# Commands

## insert

```
insert <line_number> <text>
```

Example:

```
insert 1 Hello World
```

---

## delete

```
delete <line_number>
```

Example:

```
delete 2
```

---

## display

```
display
```

---

## save

```
save document.txt
```

---

## load

```
load document.txt
```

---

## search

```
search word
```

Example:

```
search Hello
```

---

## quit

```
quit
```
